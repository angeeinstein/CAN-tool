Recording (candump format)

Records all received and (with echo on) sent frames as (epoch) can0 ID#DATA, readable by SavvyCAN, can-utils, python-can and franke_can.py decode. Markers go into a second file ….markers.txt with the same timestamps. All times are UTC. Recordings are saved continuously in this browser's storage: reloading or closing the page loses nothing, and a running recording continues after a reload (missed frames are fetched from the device; longer gaps are marked as DATA GAP).

Hidden network
Enterprise networks (eduroam, university WLAN) use a username and password (PEAP/TTLS). The server certificate is not checked, same as on many simple devices, so only enter credentials where that is acceptable. Credentials are stored unencrypted in the device's flash.
The access point franke-can (http://192.168.4.1) is always on. It shares the radio with the WLAN connection, so it moves to the WLAN's channel, and it may stall for 1–2 s while the device scans.

CAN transceiver pins

CTX (TX) CRX (RX)
Only pins that are safe for this chip are offered (no strapping pins, no pins that toggle during boot). Applying saves the pins and re-opens the bus in LISTEN.

Firmware update (OTA)

File: firmware/franke-can_<board>.bin in the project folder (copied there by every build). The bus is switched to LISTEN before flashing; the page reloads by itself afterwards.

Console

Enter runs, Shift+Enter = new line, ↑/↓ = history. Separate commands with ; or new lines; they run one after another and stop at the first #err. ; inside "quotes" or as \; does not split.
